# Mohamed Nasr — 3D Backend Engineer Portfolio

An interactive, high-performance developer portfolio showcasing backend systems engineering, distributed architecture, and identity infrastructure. Built with **Vite**, **Three.js (WebGL)**, and modern CSS.

---

## 🌟 Overview

This portfolio showcases the work, technical philosophies, and systems built by **Mohamed Abdelgawad Ragab Nasr**—a Backend Engineer specializing in **Go (Gin, standard library)** and **Node.js (Express.js)**. 

Beyond standard static portfolios, this application features a **live, interactive 3D architecture stage** representing server racks, microservice data routes, cryptographic cores, and packet telemetry rendered directly in WebGL.

---

## 🚀 Key Features

* **Interactive 3D Backend Visualizer (`src/background.js`)**:
  * Real-time 3D server module stacks with physical metallic materials and LED indicators.
  * Rotating cryptographic core (Icosahedron with wireframe bloom).
  * Dynamic data packet routing along Catmull-Rom spline curves with glow trails.
  * Orbital torus rings and ambient floating telemetry particles.
  * Postprocessing pipeline with `EffectComposer` and `UnrealBloomPass`.
  * Pointer-reactive camera tilting and smooth inertia.
  * Battery- and resource-aware: Automatically pauses the `requestAnimationFrame` render loop when the browser tab is hidden or inactive.
  * Respects `prefers-reduced-motion` user preferences.

* **Performance & Clean Engineering (`src/main.js`)**:
  * Lightweight, zero-framework architecture (vanilla ES modules).
  * Automated animated metric counters (e.g. `10,000 req/s` benchmark).
  * Scroll-spy navigation with active section highlights.
  * Smooth mobile drawer menu with accessibility attributes (`aria-expanded`, `aria-hidden`).
  * One-click email copy to clipboard with toast notification feedback.
  * Scroll-triggered reveal animations via `IntersectionObserver`.

* **Minimalist Cyber-Industrial Design (`src/styles.css`)**:
  * Dark palette (`#08090d`, `#f2f1ec`, acid accent `#d7ff4f`, violet `#8e79ff`).
  * Custom subtle noise overlay and glowing radial depth gradients.
  * Typography paired with `Manrope` (modern sans) and `DM Mono` (developer telemetry).
  * Fully responsive across mobile, tablet, and widescreen displays.

## 💻 Getting Started

### Prerequisites

Ensure you have **Node.js** (v18 or higher recommended) and **npm** installed on your system:

```bash
node -v
npm -v
```

### 1. Clone the repository

```bash
git clone https://github.com/mohnasr137/portfolio3D.git
cd portfolio3D
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

The development server will start at `http://localhost:5173` (and automatically launch in your default browser).

### 4. Build for production

```bash
npm run build
```

The optimized, minified assets will be generated in the `dist/` directory.

### 5. Preview production build locally

```bash
npm run preview
```
